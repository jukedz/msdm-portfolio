What Is a Listing?

A listing is a Quarto feature that automatically builds a page of links, like a blog index or a project portfolio, from a set of items. Instead of hand-coding a card for every project, I describe each project once, and Quarto generates the cards, the sorting, the search box, and the category filters for me.

NoteWhy listings are useful for a portfolio
  • Consistent: every project gets the same layout.
  • Easy to update: adding a project is one new entry, not new HTML.
  • Interactive: visitors can search, sort, and filter by topic.

Two Ways to Fill a Listing

  • From a YAML file (what I used)
  • From Quarto documents

All my projects live in one file, projects.yml. Each item has a title, description, link, image, date, and categories:

- title: "CEP Dashboard: Paid vs. Organic Search"
  description: "A Quarto dashboard comparing paid and organic search..."
  path: cep-dashboard.qmd
  image: images/projects/cep-dashboard.svg
  date: "2026-10-22"
  categories: [Dashboard, GA4, R]

This works best for a portfolio, because many of my projects live on other pages or in other repositories.

For a blog, each post is its own .qmd file inside a folder, and the listing reads the title, date, and categories from each post’s YAML header:

listing:
  contents: posts
  sort: "date desc"
  type: default
  categories: true

New posts appear automatically the next time the site renders.
