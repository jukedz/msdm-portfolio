About the Project

For my MSDM Culminating Experience Project (CEP), my team is consulting for the CPP Farm Store at Kellogg Ranch. Each team member leads one analytics objective, and mine focuses on the store’s websites:

NoteMy Analytics Objective (AO4)

Analyze GA4 conversion path data to evaluate whether Google Shopping Ads would improve traffic-to-purchase conversion.

The store’s own GA4 data is not connected yet, so this dashboard uses Google’s public GA4 sample e-commerce dataset (Google Merchandise Store). It has the exact same structure as a real GA4 export, so the same code will run on Farm Store data later.1

How the Dashboard Is Built

The dashboard is a single Quarto file with format: dashboard. Its headings become the layout, and each code chunk becomes a card.

  • Pages
  • Rows and Cards
  • Value Boxes
  • Theme

Each level-one heading (#) is a page in the dashboard’s navigation bar:

  • ## Row {height="22%"} creates a row and sets its height.
  • ### Conversion {width="45%"} creates a column inside a row and sets its width.
  • Every chunk with #| title: becomes a titled card, and ::: {.card title="..."} wraps text in a card.
#| content: valuebox
#| title: "Paid search conversion"
list(icon = "megaphone", color = "#C98A9B", value = percent(cr_cpc, 0.01))

Value boxes use Bootstrap icons and my brand colors, so the numbers stand out at a glance.

The dashboard uses the same theme as this website, cosmo layered with my own styles/theme.scss, and the plots use a matching color palette. That keeps the dashboard and the site looking like one brand.

Key Findings

  1. Organic search brings the most visitors of any channel.
  2. Paid search converts lower than organic search, and the difference is statistically significant.
  3. Across every channel, only about 1 in 5 visitors views a product, and fewer than 1 in 4 product viewers add to cart, so product discovery and product pages are worth improving before buying more traffic.
TipRecommendation for the Farm Store

Strengthen organic SEO first, set a GA4 baseline, and then test Google Shopping Ads in a short, tracked campaign before committing a larger budget.
