Why Style a Quarto Website?

Quarto gives every website a clean default look, but a portfolio should feel like you. With CSS and SCSS, I can control colors, fonts, spacing, and components across every page from one or two files, instead of formatting each page by hand. That keeps my personal brand consistent, which matters a lot in beauty and fashion marketing, where visual identity is everything.

NoteThe short version
  • HTML is the structure of a page (headings, paragraphs, images).
  • CSS is the style rules that decide how that structure looks.
  • SCSS (Sass) is CSS with superpowers: variables, nesting, and reusable values.

How CSS Works

Every CSS rule has a selector (what to style) and declarations (how to style it).

h2 {
  color: #6B2737;          /* property: value */
  border-bottom: 1px solid #F3D9DC;
}

  • Attributes
  • Layout

Some of the properties I use most on this site:

  • Color and background: color, background, linear-gradient(...)
  • Typography: font-family, font-size, letter-spacing, text-transform
  • Box model: padding, margin, border, border-radius
  • Effects: box-shadow, transform, transition

The home page hero uses CSS Grid to place my intro text and photo side by side, then stacks them on phones with a media query:

.hero {
  display: grid;
  grid-template-columns: 1.25fr 0.9fr;
  gap: 2rem;
}

@media (max-width: 768px) {
  .hero { grid-template-columns: 1fr; }
}

How SCSS Reduces Repetition

Plain CSS makes me repeat the same color code dozens of times. SCSS lets me store it once in a variable and reuse it everywhere. If I ever rebrand, I change one line.

Plain CSS: repeated values

h2 { color: #6B2737; }
.btn-pill { background: #6B2737; }
.navbar .nav-link { color: #6B2737; }

SCSS: one variable

$burgundy: #6B2737;

h2 { color: $burgundy; }
.btn-pill { background: $burgundy; }
.navbar .nav-link { color: $burgundy; }

SCSS also supports nesting, which keeps related rules together. Here is the real button style from this site:

.btn-pill {
  background: $burgundy;
  border-radius: 999px;

  &:hover {
    transform: translateY(-2px);
  }

  &.outline {
    background: transparent;
    border: 1.5px solid $burgundy;
  }
}

The & means “this same element,” so &:hover becomes .btn-pill:hover when Sass compiles it to CSS.

How Quarto Uses SCSS

A Quarto SCSS theme file has two special sections:

I layer my theme on top of the Bootswatch cosmo theme in _quarto.yml, so I only override what I want to change:

format:
  html:
    theme:
      - cosmo
      - styles/theme.scss
    css: styles/extras.css
TipOrder matters

Later themes override earlier ones. Because theme.scss comes after cosmo, my colors and fonts win. The extra extras.css file loads last and holds layout pieces like the hero and timeline.

Fonts

I load three Google Fonts with one @import line in the SCSS defaults:

  • Playfair Display for headings: an elegant, high-contrast serif with a fashion-magazine feel.
  • Pinyon Script for small accents, like the “Hi, I’m” on my home page.
  • Inter for body text: clean and easy to read at any size.

Accessibility

Pretty only works if people can read it. I kept dark ink text on a light cream background for strong contrast, used the script font only for short decorative words, and never rely on color alone to carry meaning.1
